## สถานะงานที่เสนอ
Product Backlog → Ready → In Progress → Code Review → Testing → PO Review → Done

## ลำดับงานเชื่อมโยงสำคัญ
- เอกสาร/OCR → คดี → คำร้อง → คืนทรัพย์สิน → รายงาน
- ข้อมูลธุรกรรม → กราฟ → คดี → Dashboard
- การยืนยันตัวตนและความปลอดภัยครอบคลุมทุกบริการ
- DevOps และ QA สนับสนุนทุก Sprint
