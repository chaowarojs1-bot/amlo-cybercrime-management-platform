# Public Disclosure Boundary

This repository is prepared for temporary public visibility. Temporary publication should still be treated as permanent disclosure: once information is public, copies, mirrors, caches, forks, screenshots, and local clones may persist after the repository is made private or deleted.

## Allowed
- high-level project purpose and scope
- public functional capability names
- high-level delivery phases and contractual day-based milestones
- vendor-neutral architecture concepts
- sanitized project-management practices
- public roadmap and documentation history

## Do not publish
- personal data or victim/case information
- bank/account/transaction data or investigation evidence
- credentials, secrets, tokens, keys, certificates, passwords
- production logs or database exports
- internal IPs, DNS names, VPN/WAF/firewall configurations
- detailed network diagrams or environment inventories
- endpoint URLs or interface credentials
- vulnerability findings or penetration-test details
- confidential contractual annexes or internal working documents
- raw source files unless separately reviewed for public disclosure

Making a repository private later does not retract copies already obtained while it was public.
